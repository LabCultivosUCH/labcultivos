# Sitio web — Laboratorio de Leguminosas y Cultivos Ancestrales

Web estática, responsive y gratuita. No necesita instalación, base de datos ni pagos.

## Ver en tu computador
Abre `index.html` en tu navegador.

## Publicar GRATIS en GitHub Pages
1. En https://github.com crea una cuenta o inicia sesión.
2. Haz clic en **New repository**. Nombre sugerido: `laboratorio-leguminosas`. Selecciona **Public** y **Create repository**.
3. En el repositorio, haz clic en **Add file → Upload files** y sube los archivos `index.html`, `style.css`, `script.js`, el archivo `.nojekyll` y la carpeta `assets` con sus SVG. Importante: `index.html` debe quedar en la raíz, NO dentro de otra carpeta.
4. Pulsa **Commit changes**.
5. En el repositorio ve a **Settings → Pages → Build and deployment**. En Source selecciona **Deploy from a branch**, en Branch elige **main** y **/(root)**, luego **Save**.
6. La dirección habitual será `https://TU_USUARIO.github.io/laboratorio-leguminosas/` (sustituye TU_USUARIO). Puede demorar algunos minutos en activarse.

Alternativa: si el repositorio se llama exactamente `TU_USUARIO.github.io`, la dirección es `https://TU_USUARIO.github.io/`.

## Editar con IA
Pide a ChatGPT o a un editor de IA que cambie `index.html`, `style.css` o `script.js`. Sube los archivos modificados con **Add file → Upload files** y confirma para actualizar el sitio.

## Antes de compartir la web
- Cambia el correo `CONTACTO@EJEMPLO.CL` por el correo oficial.
- Revisa los textos y confirma los proyectos reales y la afiliación institucional.
- Agrega fotografías autorizadas del equipo, publicaciones y enlaces DOI.
- Si agregas logos institucionales, utiliza los oficiales con autorización correspondiente.
- Los proyectos que aparecen son **ejemplos de áreas de trabajo**, no títulos ni adjudicaciones confirmadas.

## Archivos
- `index.html`: contenido y secciones de la web.
- `style.css`: estilos, colores, diseño responsive.
- `script.js`: menú para móviles y año actualizado.
- `assets/`: ilustraciones SVG locales y favicon.
- `.nojekyll`: evita procesamiento innecesario de Jekyll.

Esta web NO incluye formulario con envío de datos, ni servidor: el botón de contacto abre el cliente de correo del visitante.
